# 👋 Hola, soy Fernando — Ingeniero en Software | Desarrollo Web y Cloud

Soy un **Ingeniero en Software especializado en sistemas web escalables**, combinando arquitectura sólida de backend con experiencias modernas de frontend.
Enfocado en **consistencia de datos, optimización en la nube y lógica de dominio limpia**, construyo sistemas eficientes, mantenibles y seguros.

---

## 🚀 En lo que estoy trabajando

* Diseñando sistemas modulares usando **Arquitectura Hexagonal** y buenas prácticas de código limpio.
* Construyendo APIs robustas con **Node.js**, **Laravel** y **TypeScript**.
* Implementando **comunicación asíncrona** con RabbitMQ y servicios en la nube como **AWS**, **Google Cloud** y **Digital Ocean**.
* Integrando **Flutter** para aplicaciones móviles multiplataforma con interfaces limpias y arquitectura mantenible.

---

## 🧠 Qué me motiva

Creo que un gran software es **un ecosistema**, no solo un conjunto de líneas de código: debe escalar, evolucionar y proteger los datos de manera inteligente.
Estoy constantemente refinando mi entendimiento de **domain-driven design**, **optimización de recursos** y **patrones de persistencia de datos**.
